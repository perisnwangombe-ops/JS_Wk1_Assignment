# Personalized Webpage - Week 1 Project

## Project Description
This is an interactive personalized webpage created as part of Week 1 project. 
The user can input their name and age, and the webpage displays personalized content using JavaScript.

## Features Implemented
- Form for user to input **name** and **age**
- Data is stored in `localStorage` (persists even after refreshing the page)
- Personalized greeting using template literals
- Function to calculate and display user's **age in months**
- `if...else` conditional statement to check if user is over 18 (Adult Content section)
- Motivational quote displayed **five times** using a `for` loop
- Clean and simple styling using plain CSS
- Responsive and user-friendly design

## Project Structure
The project has been created using **three separate files**:

- `index.html` - Contains the HTML structure
- `style.css` - Contains all the styling (plain CSS)
- `script.js` - Contains all the JavaScript logic

## Technologies Used
- HTML5
- CSS, tailwind
- JavaScript 

## How to Run the Project
1. Download or create the three files:
   - `index.html`
   - `style.css`
   - `script.js`
2. Place all three files in the **same folder**
3. Open `index.html` in any web browser (double-click the file)

## How to Deploy on GitHub Pages
1. Create a new repository on GitHub
2. Upload the three files (`index.html`, `style.css`, `script.js`)
3. Go to **Settings** → **Pages**
4. Under "Source", select **Deploy from a branch** → `main` → `/ (root)`
5. Click Save
6. Your live site will be available at: `https://yourusername.github.io/repository-name`
